# client-scoring-api
API de scoring de risque de crédit : prédit la probabilité de défaut de paiement d'un client à partir de ses informations (revenu, historique de crédit, motif du prêt, etc.), via un modèle XGBoost. Une interface web (**Streamlit**) est fournie pour tester l'API via un formulaire, sans écrire de code.
